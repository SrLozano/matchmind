# Local discovery data

This directory is reserved for provider discovery output generated by the
exploration scripts. Raw provider responses must remain local and must not be
committed or redistributed.

The application expects these default local paths when a discovery seed is
used:

- `tmp/odds_api_world_cup_discovery.json`
- `tmp/polymarket_world_cup_discovery.json`

Generate the files locally with the corresponding scripts and keep them
untracked.
